# API reference

The API is auto-generated from the docstrings, which are written in English — so
there is one generated page rather than a translated pair, and it lives at the
site root:

[Open the API reference →](https://mauriciobenjamin700.github.io/tempest-core/reference/){ .md-button }

It documents every public symbol of `tempest_core`: `App`, `build`, `diff`,
`Style`, the widgets, the components and the cross-cutting helpers. An absolute
link on purpose — a relative one to a generated directory is what MkDocs reports
as an unrecognized link, and `--strict` turns that into a failed build.
